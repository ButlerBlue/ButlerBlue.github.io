# ButlerBlue.github.io

Personal portfolio and writing archive for Stephanie Dlatt, an Implementation Specialist building Salesforce integrations, single sign on, and API architecture.

**Live site:** [butlerblue.github.io/StephanieDlatt.github.io](https://butlerblue.github.io/StephanieDlatt.github.io/)

**What's here**
- A case study on building a Salesforce integration for a vendor's platform with no direct access to their system
- A section on leadership evidence at the individual-contributor level: process changes that got adopted, cross-team advocacy, and enablement built for other roles
- An archive of posts originally published on [LinkedIn](https://www.linkedin.com/in/sdlatt)

Plain HTML and CSS, no build step, no framework. Served directly by GitHub Pages from `index.html` on the `main` branch.
